# Data provenance and public boundary

This release contains a curated export with a fresh history. The original research checkout and its private history are not part of the release.

- `config/` comes from the previously sanitized local runtime fixture. It preserves modelling inputs and source-status labels. Six private document-path citation strings across the annual profile and saved library were replaced by a plain attribution to reported estimates. No numerical value was changed by that replacement.
- `data/processed/topic_catalog.csv` contains 90 anonymized topic labels, eligibility flags and aggregate counts. It has no employee roster. People, demand fixtures and event identities generated by the model are synthetic.
- `SOURCE_MANIFEST.json` verifies 15 packaged configuration files; `DERIVED_DATA_MANIFEST.json` verifies the anonymized topic catalog. These are included-input integrity checks, not access to or verification of original private sources.
- `HANDOVER_MANIFEST.json` identifies the canonical public engine and input bytes.
- `dashboard/static/library.json` is a frozen aggregate projection of the historical 420-run study. Its manifest retains original study identifiers and the prior library hash, and records the sanitized projection's new hash. Citation-only edits do not turn that historical audit into a new public-fixture study.
- `site/data/` contains frozen comparison, frontier and sensitivity aggregates with their original source hashes. The private archived tables needed to rebuild them are excluded.
- Original documents, raw/reference files, employee-level information, internal service links, credentials, private Git history and full historical run exports are excluded.

## Code and data attribution

This export adds no new software or data licence grant. Existing third-party rights remain with their owners. The included aggregates are published as attributed research evidence; retain their source-status labels and limitations when quoting them.

## Export changes

The dashboard now imports the canonical `src/` engine and reads the root input manifests. Its default experiment directory is local and ignored. Generated engine provenance uses `src` or `external_install` instead of an absolute user path. The three missing test helper modules were included, the input-integrity expectation was adapted to the public fixture, and the public run path is asserted. The numerical simulation mechanics were not changed for this export.
